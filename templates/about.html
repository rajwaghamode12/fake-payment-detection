About FraudShield AI

AI-Based Online Payment Fraud Detection and Risk Analysis System — Academic Demo

FraudShield AI

A full-stack, machine-learning-powered web application that detects fraudulent online payment transactions using a multi-layer AI pipeline.

Python 3.11 Flask 3.0 Scikit-learn XGBoost SQLite Bootstrap 5 Chart.js

Academic demo system. Uses synthetic data only. Not for real banking use.

System Workflow
  1. User inputs simulated transaction details
  2. Input validation & feature engineering
  3. ML Classification (Random Forest / XGBoost)
  4. Isolation Forest anomaly detection
  5. Behavioural profile comparison
  6. Transaction velocity analysis
  7. Dynamic risk engine combines all signals
  8. Risk Score 0–100 is calculated
  9. Explainable AI generates reasons
  10. Result stored, alerts triggered for HIGH/CRITICAL
  11. Admin reviews flagged transactions
  12. Feedback stored for model retraining
